XHR Triggered in Load-Phase of a Page Load

This page starts its XHR during the initial lifecycle using DOMContentLoaded, which keeps it close to the initial navigation.

Run mode: manual mode
This scenario auto-starts on every page load because the XHR belongs to the page load lifecycle.
Lifecycle markers:
  • The request starts from DOMContentLoaded.
  • window.load is also logged so you can compare the two phases.
  • Use this page when you want the XHR to be associated with the initial load rather than a later user action.
