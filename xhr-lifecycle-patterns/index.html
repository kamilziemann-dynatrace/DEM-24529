Open Synthetic guide

Recommended Synthetic setup:
  • Target a specific scenario page instead of the index page when you want a single, repeatable waterfall.
  • Use ?autorun=1 on the two pages that otherwise start from a button click.
  • Keep the JSON fixtures same-origin and relative, because GitHub Pages will then serve them without CORS noise.
