iFrame Test Scenarios

DEM-24529 — Test pages for Dynatrace Synthetic Monitoring waterfall analysis

1. Cross-Origin iFrame with Resources

Cross-origin iframe (CodePen) + external images (Unsplash, WebP) + inline SVG. Buttons to fetch data and load images dynamically.

cross-origin iframe images

2. Same-Origin iFrame

Same-origin iframe with its own resources. Auto-loads image + fetch on page load. Buttons for XHR, dynamic image loading, and panel toggle.

same-origin iframe fetch + XHR

3. Cross-Origin iFrame with Navigation

3-page navigation flow. Each page loads a different cross-origin iframe + resources. Navigate between pages to see waterfall per page load.

cross-origin iframe multi-page navigation fetch + XHR

4. Nested iFrames

3-level nesting: outer page → same-origin middle iframe → same-origin inner iframe. Each level loads its own resources and has interactive buttons.

nested 3-level mixed origins fetch per level

5. Mixed iFrames (Same + Cross Origin)

Single page with both same-origin and cross-origin iframes side by side. SVG, images, fetch, XHR. Toggle iframe visibility.

same + cross origin fetch + XHR

6. iFrame with Heavy Fetch Activity

Both parent and iframe actively fetch data. Auto-loads fetch + XHR on page load. More fetches triggered by buttons. Cross-origin iframe included.

same + cross origin heavy fetch + XHR

7. SPA with Hash Routing + iFrames

Single-page app using hash (#) routing. Each view loads different iframes and resources dynamically without page reload. 4 views: home, page1, page2, page3.

SPA hash routing dynamic iframes fetch per view

8. SPA with History API + iFrames

Single-page app using History API (pushState). Views: home, dashboard, reports, settings. Each loads different iframes and resources. Back/forward navigation supported.

SPA History API dynamic iframes fetch + XHR + POST
